# Contributing to SINWAR

Thanks for contributing.

## Before You Start

Please make sure your changes are:

- Focused and easy to review
- Tested locally
- Documented when behavior changes
- Compatible with the supported Python version

## Development Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run the application:

```bash
python3 cli.py
```

## Pull Requests

A good pull request should include:

1. A short description of the change
2. Why the change is useful
3. Testing performed
4. Any documentation updates

## Security

Please do not include real credentials, API keys, tokens, private data, or unauthorized target information in issues or pull requests.

For security-related concerns, avoid publicly posting sensitive details before responsible disclosure.
