# SINWAR v1.0.0

## 🎉 First Stable Release

SINWAR v1.0.0 is the first stable release of the project.

### Highlights

- 🔐 Crypto utilities
- 🌐 Network utilities
- 🛡️ Web security toolkit
- 🔤 Encoding tools
- 🔑 Password generator and local manager
- 🖥️ Interactive CLI
- 🐧 Linux setup documentation

### Web Security

- Directory discovery
- Security headers analysis
- robots.txt / sitemap checks
- Basic technology detection
- JavaScript endpoint discovery
- Benign input reflection checks

### Password Manager

- Random password generation
- Custom password length
- Character-type selection
- Save / view / delete functionality

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/SINWAR.git
cd SINWAR
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 cli.py
```

### Responsible Use

Use SINWAR only against systems you own or have explicit permission to test.
