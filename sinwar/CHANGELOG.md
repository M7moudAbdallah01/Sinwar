# Changelog

All notable changes to SINWAR are documented here.

## [1.0.0] - 2026-10-08

### Added
- Interactive CLI
- Crypto utilities
- Network utilities
- Encoding utilities
- Web security module
- Directory discovery
- Security headers analysis
- Robots.txt / sitemap checks
- Basic technology detection
- JavaScript endpoint discovery
- Benign input reflection checks
- Password generator
- Local password manager
- Linux installation documentation
- Responsible-use documentation

### Security
- Password generation uses Python's `secrets` module.
- Local password storage is excluded from Git through `.gitignore`.

### Notes
- The password manager stores local JSON data and is not intended to replace an encrypted password vault.
